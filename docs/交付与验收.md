产品常驻 system section 从 10,392 变为 1,346 UTF-8 字节。受控请求中的目录消息（JSON 序列化含封装）为 2,070 字节，工具 schema 为 36,461 字节；按需加载后的研究/委托/投资正文消息分别约 9,262 / 2,743 / 1,619 字节。空消息列表序列化为 2 字节，不能当成加载了正文。完整 system 消息还受 DSH 原生上下文影响。仅报告字节，不报告实测 token、费用或质量提升；目录和加载正文仍消耗输入，工具 schema 没有消失。
