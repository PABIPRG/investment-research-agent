## 本批实际行为

- 风险偏好继承三题/八题、待核对文字填答、滑块、原推断/有效画像、版本历史、三档预算和确定性研究护栏；保存复用投资事实预览和原生确认。
- 个性化通过 Tool 读取卡片、策略匹配、反馈和本机学习；新增正式状态仅承接当前主体的学习开关、反馈和幂等回执。默认暂停，不恢复旧 JsonStore 或完整 Agent。
- 持仓止盈止损通过 Tool 预览及同一投资事实确认；全局/单仓覆盖、冻结成本和重新布防投影现有委托核心。程序复用 execution/attempt/lease 执行价格条件，不增加独立 Agent 或调度器。
- 四类研究、多空辩论和三类风险审查作为 DSH Skill 方法，结构化审查 Tool 绑定同主体同会话证据和当前画像，保留原建议及校准结果；材料不足保留 unknown。
- 研报正文 Tool 限定公开来源和列表内报告，限制大小、页数、时间与解析子进程；关系引用资格不接受仅有标题、评级或报价的材料。基础档案与搜索不依赖关系种子。
- 启动模型配置沿用设置页，关闭自动密钥弹窗，并兼容已知旧版产品补丁。问答卡片复用原生 DSH，仅调整主题、圆角、说明布局和视觉状态。
- 209 条旧 HTTP 入口台账用于追溯和防遗漏；不等于新增 209 个 Tool，不等于所有能力已完成。
