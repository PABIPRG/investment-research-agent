# V1.4 行情与新闻资料迁移

本页记录 2026-10-27 的有界资料切片，不代表委托、DSH、通知或浏览器完整验收。来源基线为旧仓 `public/master` 的 `9c23b1fdb249d8192748196cb183709e8e2030f4`；逐文件来源摘要见 `sidecar/huohuo/market/provenance.json`。

## 复用与状态边界

| 用户动作 | 原接口与所有者 | 决策 | 迁入方式与边界 |
| --- | --- | --- | --- |
| 查询指定股票行情 | market-watch quotes.py | Extend | 复用东财 ulist、新浪 hq；补来源时间、统一成交量单位、缺失与过期标记 |
| 看全市场排名或异动候选 | quotes.py + scanner.py | Extend | 保留服务端排名，显式 scan 才运行；不默认读取第二套自选，不遍历全部证券 |
| 查看技术信号 | indicators.py + quotes.py K线 | Compose | 指标纯算法原样迁入；东财前复权日线主源、新浪未复权明确降级 |
| 查看个股新闻与财经快讯 | news.py | Extend | 复用东财定向搜索、Sina/CLS 快讯；稳定 ID、来源/发布时间独立保留 |
| 盘前/盘后资料准备 | briefs.py + quotes/news | Compose | 有限报价、四个指数与快讯资料包；DSH 解释，委托负责日程与通知资格 |
| 判断交易日 | 旧 quotes.py `_calendar`、AKShare 静态解码器 | Extend | 修复旧路径误当纯文本日历；明确覆盖区间、实例缓存、失败关闭 |

MarketData 不拥有用户/委托/提醒/策略/自选正式状态，不启动后台调度，不调用旧 LLM，不发送通知。正式来源快照、证据、去重事件由既有 Sources 和委托核心持久化。数据只在当前服务内短期缓存；仅交易日历可写入调用方指定的实例缓存文件。

## 接口

`from huohuo.market import MarketData, TradingCalendar, CalendarUnavailable`

`MarketData(provider=None, *, clock=time.monotonic, now=utc_now, capacity=4).query(request)`。
测试可注入 `provider(request)`，时钟 `clock()` 返回单调秒，`now()` 返回带时区 ISO 字符串。

| operation | 参数 | data |
| --- | --- | --- |
| quotes | `codes`，1–20 个明确沪深 A 股代码 | `items, requested_codes, missing_codes` |
| scan | `kind=gainers/volume_ratio/limit/turnover/amount`；`limit=1..50` 默认 10；`min_amount_yi=0..10000` 默认 0 | `kind, universe, candidate_limit, items`；limit 另含 limit_up/down |
| technical | `code`；`lookback=20..250` 默认 120 | `code, bars, through, adjustment, indicators, summary, units, time_precision=date` |
| news | 可选 `code`；`limit=1..50` 默认 20 | `items, limit, code, window`；不提供 code 时为快讯 |
| brief | `codes`；`period=pre/post` | `period, quotes, indices, news`，后三项分别为完整子 envelope |

所有响应：`{status: ok/empty/unavailable, source, as_of, time_known, observed_at, stale, complete, warnings, data, cache?}`。
非法请求抛 `huohuo.contracts.Invalid`；资料失败返回 unavailable，不等于空结果、无变化或条件不满足。unknown 数值为 null；不输出 NaN/Infinity。

股票 `items`：`code/name/price/previous_close/pct_change/volume_ratio/turnover/amount_yi/volume/source/source_url/as_of/time_known/observed_at/units/stale`。
价格为 CNY/share；pct_change 与 turnover 为百分数（1 表示 1%）；volume_ratio 为比例；amount_yi 为亿元；成交量统一为股（东财手数乘 100，新浪直接股数）。指数 price/previous_close 为 point，指数成交量保留 source_lot/source_volume 单位，不与股票成交量混用。

技术字段保留旧算法结构：`indicators.rsi.rsi14`、`macd.hist/dif/dea/cross`、`ma.ma5/ma10/ma20/ma60/trend`、`kdj`、`boll`、`support_resistance`、`pattern`。日线 source time 仅精确到日期，以该交易日上海时间 00:00 表示，`data.time_precision=date` 明示；不冒充实时成交时间。新浪日线明确 `unadjusted`，不估算缺失成交额。新股短历史和无效 OHLC 行会令 complete=false。

新闻条目：`id/title/content/url/source/provider/source_url/published_at/time_known/observed_at/code?`。
ID 为来源文章 URL（缺少时用固定 feed URL）＋标准化发布时间（未知 null）＋标题的 SHA256；采集时间不参与 ID。发布时间未知不补成采集时间。`source` 保留原始媒体，`provider` 表示连接源。定向搜索结果需核对相关文章相关性，不等同于上市公司正式公告。

## 时效、完整性与限制

- quotes/scan 报价来源时间超过 180 秒或未来超过 30 秒，stale=true；没有来源日期时间则 time_known=false、complete=false。盘后当天收盘快照因此可读但不属于盘中实时资料。盘前/盘后简报的收盘参考资格应由集成层按交易日历、period 和来源交易日期另行判断，保留原 stale。
- technical 最新日线超过 4 天或日期异常会标 stale；仍可用于历史回看，不能直接触发新提醒。
- `complete` 与 `stale` 独立。完整字段的旧收盘快照可以 complete=true、stale=true。所有消费者须同时核对来源时间、适用口径、所需字段和来源覆盖。
- scan 是全市场服务端排名的有限候选，不是全量穷举。成交额过滤最多覆盖前 150 条候选。涨跌停扫描各取涨/跌排名前 100 条，以涨幅阈值给出候选，complete=false；不冒充交易所涨跌停确认，新股/特殊规则需继续核对。
- 新浪报价缺少量比与换手率，保留未知；量比扫描没有伪造的新浪替代。Sina 排名没有完整交易日期，不能当实时触发依据。
- 新闻只读各来源最新一页；不保证穷举历史或全部媒体。单源失败的快讯可以返回部分数据，complete=false；两个源均失败为 unavailable。
- 查询子进程 18 秒总截止，固定域名 HTTPS、保留 TLS 校验、单响应最多 2 MB、默认最多 4 个并发查询。共享请求不会无限排队。
- 内存缓存最多 128 项，正常 TTL 为 quotes 10 秒、scan 20 秒、technical 600 秒、news/brief 60 秒；源失败时仅有限返回旧缓存，明确 stale=true、complete=false，且不刷新原来源/采集时间。

## 日历和事务

`TradingCalendar(cache_path=None, loader=None, *, now=utc_now)`。
调用方在 SQLite 事务外显式 `refresh()`；`is_trading_day(datetime.date)` 仅读内存快照，无网络与磁盘写入，也不等待刷新网络锁。未加载、过期或超出覆盖区间抛 CalendarUnavailable，不按周一到周五猜测。

固定源为新浪公开交易日历，使用依赖 AKShare 内置的静态解码算法；来源文本只提取编码数据，不执行远端脚本。保留来源 URL、observed_at、coverage_start/end、trading_days。成功缓存一天，刷新失败可使用最多 7 天且在覆盖内的缓存；失败 60 秒退避。缓存由实例路径隔离，原子替换、0600 权限。不得在委托事务中隐式刷新；调度异常不能按“正常交易日”放行。

## 2026-10-28 来源覆盖补齐

日线增加 Baostock 第三回退，次序为 Eastmoney → Sina → Baostock。各自保留复权口径；Sina 未复权降级不能变成完整触发证据。依赖锁定 `baostock==0.9.4`，SDK 使用匿名公共明文 TCP，明确标注 `plain_tcp_public`，不传用户凭据、不关闭 TLS 校验。
