## 程序与模型边界

- 程序：题库与分数、手动调整、画像预算、身份与版本、成本阈值、计划状态、规则资格、幂等、通知与审计。
- DSH：自然语言答案候选、研究分析与辩论、资料语义提取、解释、候选建议。答案须逐项核对；关系须有合格材料与定位；建议不能自行成为业务事实。
- 仅恢复能力，不自动恢复旧运行状态、监控授权、原生权限、密钥、行为跟踪或交易。用户明确设置后进入对应闭环。

## 实施顺序与失败恢复

1. 风险画像：题库/滑块/自然语言补答 → 画像预算/风险读模型。沿用 Investment 原子预览和确认，不另存第二份 preferences。
2. 持仓风险计划：全局/单仓/成本投影/激活代次 → 同一委托核心、事实修订和通知资格。配置变更先撤销旧执行资格；无成本、无持仓、配置失效和未知行情分别呈现。
3. 个性化：先复用确定性匹配、卡片、行为及归因算法，增加本机领域状态与页面/聊天接口；停用学习即停止记录，清除只影响该主体的学习状态。
4. 研究资产：DSH 研究方法与历史决策评价、产业链正文证据、基础档案门控、原看盘语义逐项接入。
5. 券商本机适配、完整数据进出及剩余界面；真实权限/外部来源未知项如实记录，不能以模拟通过消项。
6. V1.4 契约与交付差异：后台范围、Repository 隔离、双安装路径、升级回退。按实际依赖串行，不借补功能恢复第二个 Agent 或独立调度器。

所有写入沿用预览/明确确认、事实或领域版本、幂等回执；连接中断保留未知结果并查询原回执，不新建重复操作。迁移使用新增向后兼容字段或正式 SQL 迁移，旧文档默认状态只读兼容，缺失不伪造完成。新旧进程和缓存不共享，正常实例升级另行验证。
