# 委托 Hook 统一门禁实施与验收

更新：2026-10-29。本文记录用户已批准设计的第一阶段实现，不将完整目标设计、真实模型质量、用户试用或发布视为已完成。概念入口见[程序化 Hook 与研究触发](../概念/程序化Hook与研究触发.md)，完整目标见[获批设计](V1.4-委托Hook前置与模型调用门禁设计.md)。

## 当前行为

普通研究和策略候选在构造运行时之前向委托核心核验触发依据；提交模型 prompt 之前再次核验。领取任务和客户端布尔标记均不构成模型调用许可。

| 情况 | 行为 |
|---|---|
| 没有可信 Hook 或明确的当场研究请求 | 拒绝模型执行，保存原因 |
| 事件未命中当前依赖、资料被替代、过期或口径未知 | 不启动模型，不把未知记成条件未满足 |
| 价格、涨跌幅、量比、换手率、RSI、MACD 等已支持的纯数值条件及 all/any 组合 | 程序取数、校验并提交结果，再走既有联系判断；不调用模型 |
| 纯数值条件未满足或满足 | 均不调用模型；是否联系继续按已保存的规则、状态和发送资格处理 |
| 有效语义资料复核或必要的初次研究 | 当前资格与可信触发均有效时，允许本次有界模型研究 |
| 定时成果交付、确定性周期检查 | 创建时不抢跑，真实到期后按任务类型执行 |
| 明确到期提醒 | 沿用既有直接提醒，不调用模型 |
| 暂停、改约、租约失效或取消代次不一致 | 拒绝旧任务的后续模型请求 |
| 本次模型提交资格已经预占 | 不自动再次提交；结果未知时不释放资格后重放 |
| 混合或不支持的联系条件，缺少独立研究触发约定 | 返回可解释的受阻原因，不自动补造模型研究授权 |

本轮复用现有 Hook。完整业务条件事件家族、独立研究触发配置、阈值命中后额外语义研究、跨任务额度账本以及 token/金额硬上限不在第一阶段完成范围。

## 持久化、恢复和兼容

准入复用既有 `events`，保存 `model.admission` 和 `model.submission_reserved`，绑定 execution、attempt、委托修订、取消代次、可信事件、来源版本与规则摘要。明确当场研究另绑定经用户接口认证保存的 `research.requested` 事件。

提交资格在同一个数据库写事务内预占，并发只能取得一次。预占后 worker 崩溃或回执丢失，不自动重新调用模型；保留未知并按原执行恢复流程核对。人工请求和后台静默重试分开处理。

领取接口要求 `hook-model-gate-v1`。旧 worker 不能从新侧车领取任务；新 worker 收到旧接口、缺失或错误绑定的回执时不放行。升级须停止旧 worker，成组更新 worker 与侧车；已经发出的外部模型请求不能因升级被追溯撤回。

遇到兼容故障时保留业务数据和执行审计，暂停受影响任务后核对。回退不得关闭门禁或恢复无条件模型调用；旧版本恢复前必须隔离不能识别的新规则。

## 正常产品与用户试用边界

本地正常产品曾通过正式安装包与三个 Profile 启动，真实东方财富资料驱动价格 `11.52 CNY/share < 10` 的程序检查；当时两次执行的持久化模型提交预占为 0，未产生提醒，随后暂停并经浏览器刷新回查。该单次证据不证明长期来源可用或模型账单。

整合 PR #6 后保留其价格程序执行标识、状态原因与账户/UI 修复。其他通用数值执行仍复用研究结果台账，因此页面记录数量不能作为模型调用次数；尚未新增完整的“等待依赖/补充触发约定”恢复交互。

用户已明确选择自行试用，停止由代理代做真实模型验收。本轮 PR 不以受控模型、程序价格检查、服务启动或网页认证证明真实语义研究成功；完整真实 UAT 结论仍为 **Inconclusive**。外部通知、来源长期可用、真实收盘调度、非空实际组合与跨平台安装继续保持未验证。

浏览器首次进入必须使用当前进程完整认证地址，Cookie 在不同浏览器之间不共享。网页认证与模型 API Key 分开处理；凭据由用户在正常设置表单保存，不写入源码或 PR。启动 main 时应核对已合并提交与安装包指纹，不能把功能分支的旧安装包冒充 main 构建。

项目追溯沿用 PAB-48 / PAB-49，不因本地检查或 PR 创建自动更新为 Done。提交、推送、PR、合并、发布与服务器操作分别遵守用户授权；本轮不部署或操作用户远程服务器。
