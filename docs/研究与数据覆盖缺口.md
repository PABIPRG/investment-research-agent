# 研究与数据覆盖缺口

本文件记录“用户问一个投资问题，产品能不能找到证据”的实际覆盖情况。结论只依据已注册工具和本机实测过的数据源，不代表全部数据源长期在线。

## 1. 结论

- 聊天侧现有 66 个研究工具、92 个聊天工具。市场层面（板块、指数、情绪、涨停、快讯、ETF、估值）已经可以不经实体确认直接查询。
- 本轮补齐了卖方观点与一致预期、公告原文链接、业绩快报、港美股历史行情、汇率即期、分钟线、债券收益率曲线与 IPO 发行信息。
- 仍缺的集中在：财报三表明细、公告 PDF 正文解析、期权链与基差、北向个股明细、增减持/回购、完整板块成分、基金评级与舆情。
- 遇到缺口时，产品应返回 `empty` / `unavailable` 并说明原因，不能用相近数据冒充。覆盖缺口不是“换个说法就能回答”的问题。

## 2. 本次补充的能力（18 个）

| 工具 | 回答的问题 | 数据源 |
|---|---|---|
| `sector_ranking_lookup` | 今天哪些行业/概念板块强、涨幅与资金流入排行 | 同花顺行业一览、概念资金流 |

| `etf_ranking_lookup` | ETF 涨幅/成交额排行 | 新浪场内 ETF 行情 |
| `performance_forecast_lookup` | 哪些公司预增/预减、业绩变动幅度 | 东方财富业绩预告 |

## 4. 缺口现状（2026-10-27 实测）

已补齐的缺口用 ✅ 标注；仍缺的写清具体阻断原因，不能用相近数据冒充。

| 缺口 | 状态 | 现状与替代 |
|---|---|---|
| 研报、评级、一致预期 | ✅ 已补齐 | `research_report_lookup` 返回研报清单、评级、机构与年度 EPS 预测；一致期望值是样本内算术均值，不是全市场一致预期。 |
| 财报三表全文、业绩快报 | ⚠️ 部分 | 业绩快报见 `performance_express_lookup`；资产负债表/利润表/现金流量表明细仍缺：新浪三表接口单只股票需 20~60 秒且本机多次超时，东方财富三表接口走被阻断的 push2。 |
| 公告正文 PDF | ⚠️ 部分 | `announcement_document_lookup` 返回巨潮公告清单与原文链接；不解析 PDF 正文，版权与解析成本需单独评估。 |
| 港股、美股、汇率 | ✅ 已补齐（历史与即期） | `overseas_quote_lookup` 用新浪历史日线；`forex_rate_lookup` 用东方财富外汇即期。实时盘口/撮合快照仍依赖被阻断的 push2。 |
| 期权、期货基差与持仓 | ⚠️ 部分 | `commodity_price_lookup` 已有期货主力连续价格与持仓量；期权链接口返回空表、基差仍需专门数据源。 |
| 北向资金个股明细 | ❌ 仍缺 | 行情汇总接口返回的北向净买额已被披露口径调整为 0，个股持仓接口超时；不得把成交额或南向数据当成北向。 |
| IPO、增减持、回购 | ⚠️ 部分 | `ipo_detail_lookup` 已覆盖发行信息；全市场增减持与回购接口 90 秒内未返回，未接入。 |
| 完整板块成分 | ❌ 仍缺 | 东方财富板块成分接口走 push2 被阻断，同花顺只有板块一览、无成分接口；`theme_constituents_lookup` 仍只抓涨幅排序前几页。 |
| 分钟线、tick、盘口 | ✅ 部分（分钟线） | `minute_bar_lookup` 覆盖 1/5/15/30/60 分钟、最近几个交易日，未复权；tick 与盘口成本高，未接。 |
| 债券收益率曲线、信用利差 | ✅ 部分 | `bond_yield_curve_lookup` 已覆盖国债/国开/中短期票据曲线；信用利差需自行用同期限曲线相减，工具不直接给利差。 |
| 高频宏观、预测数据 | ❌ 仍缺 | `macro_series_lookup` 只有已发布序列；宏观一致预期依赖付费源。 |
| 互动易、舆情、股吧情绪 | ❌ 仍缺 | 只有人气榜反映关注度；抓取稳定性与合规风险高。 |
| 基金评级、基金经理 | ❌ 仍缺 | 全量评级接口 90 秒内未返回；净值与持仓已有。 |

## 5. 数据源稳定性与口径

本机实测（2026-10）确认：

- 东方财富 `push2.eastmoney.com` 直连被阻断；`push2ex`（涨停池）、全球快讯可用。涉及 push2 的工具必须保留失败告警。
- 同花顺行业/概念资金流、板块一览可用，是板块类工具的主来源。
- 新浪指数与 ETF 行情可用；乐咕赚钱效应页面结构曾变化，失败时回退东方财富全 A 涨跌家数。
- 财联社电报接口不稳定，`market_news_lookup` 只把它作为补充来源并设置较短超时。
- 所有工具返回 `status`、来源、抓取时间与 `evidence_id`；`empty` 不等于对象不存在，`unavailable` 不等于没有这项数据。
