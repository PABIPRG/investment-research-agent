| 状态 | 适用与呈现 |

## 与批准示例的差异及集成边界

- HTML 示例只确认信息组织；按用户反馈，复用已有品牌、导航、DSH 主题与共享 Page / Controls，移除原候选中偏离产品风格的灰底、独立圆角卡片和方形控件。
- 不生成示例里的持仓变更动态、阶段百分比或研究未读数；首版筛选为全部/研究结果/提醒，联系渠道按同一决定合并后保留不同回执。
- 研究结果可定位到确切 execution；提醒沿用确切 decision 回访。待回答操作回原 DSH 对话，动态不提供第二套批准/撤销系统。
- 最新范围明确为 48 小时；较早、未知或异常未来时间的已读取记录留在历史。已知分页未读全时不报告全量零项。
- 依赖基线 ac9ed0f 的委托进展代码已在主线；本分支整合 main 8119b24 中已经合入的全局提醒/刷新，保留主线的唯一火火和读取隔离，不纳入其他 worktree 的未提交改动。
- 回退可在后续集成时撤销本任务的 UI 增量；无数据库迁移、授权变更或新外部副作用。
