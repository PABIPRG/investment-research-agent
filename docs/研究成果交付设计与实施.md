## 契约

- 模型选择格式、列与分析内容；程序生成 ID、时间、归属、文件名、字节、摘要及下载地址。来源引用由程序按主体/会话读取，不相信模型重抄数值。
- 支持原始证据导出和模型整理表格。表格逐项注明内容性质，保留来源、报告期、单位及限制；缺失值不转为零。原始 JSON 保留嵌套结构。
- 侧车生成 CSV/JSON/XLSX，成果位于本实例受控目录。每次工具调用生成稳定标识；相同调用重放只返回同一成果，不覆盖；参数冲突失败。临时目录全部生成成功后才原子发布，崩溃残留不对外可见。
- 程序限制格式、表数、行列、文本和总字节。拒绝任意路径、公式和外部引用；Excel 文本单元格强制文本；CSV 处理电子表格公式与代码前导零，明确空值约定。
- 文件和元数据包含独立来源说明。原始数据、模型整理、生成时间与数据时间分开。旧成果为当时快照，不代表当前行情。
- 生成与下载复用现有用户认证。下载只接受成果标识，不接收本机路径。重新打开会话或服务重启后仍可取回；文件缺失或校验失败显式报错。
- 首版不开放 shell、任意写文件或任意 present 路径。交付展示使用 DSH 的已发布扩展点；若原生 present 的路径接口无法满足归属边界，则由产品受控适配器登记同一交付协议。
- 不迁移既有业务表；成果新增目录不影响旧实例启动，安装包声明直接使用的 Excel 依赖。升级只更新产品受管文件，保留用户 Profile。

## 体验契约与状态

从 AI 对话发起，生成后展示文件名、格式、大小、来源说明和下载操作。复用现有对话与主题，不新增一级导航。支持 1440/1024/768/390px、深浅主题、键盘与可访问名称。

首版只提供下载：火火布局没有展示 DSH 右侧预览，因此在研究交付卡片内移除该预览点击层和悬停提示，保留原生布局、文件名与真实说明。深色卡片使用火火语义背景和文字 token，避免系统主题与原生中性色切换不一致导致低对比度。

| 状态 | 行为 |
|---|---|
| 加载/禁用 | 生成中不声称成功；下载期间防重复操作 |
| 空数据 | 可交付有表头/元数据的空结果，明确无记录 |
| 部分成功/过期 | 显示来源限制及数据时点，不能补造缺项 |
| 错误/无权限/缺失 | 保留原成果引用和明确错误；可重试读取，不自动重做研究 |
| 成功/刷新 | 文件独立保存，刷新与重启后内容不变 |
| 筛选无结果 | 首版无成果筛选界面，不适用 |
| 确认/撤销 | 用户请求即授权生成新的副本；不改持仓或外发，无额外确认/撤销 |

## 实施与验证顺序

1. 先写失败测试：格式、类型、来源归属、不可覆盖、原子失败、重启、路径/认证拒绝。
2. 实现侧车成果与序列化，接入可信会话 Tool；接入受认证下载与对话展示。
3. 同步 Skill、允许名单、能力目录、安装升级和直接依赖。
4. 跑聚焦 Python/Node 回归、capabilities/check/build。真实浏览器走聊天生成三种格式、下载并解析，验证刷新/重启与失败、主题和窄屏。
5. 自审改动及授权边界，将证据与未验证项回写 PAB-67；未经授权不提交、不推送、不发布。

## 风险与回退
