# 火火投研伙伴


- [V1.4 UI 与交互设计](docs/设计基线/V1.4-UI与交互设计.md)：已批准 r1 交互稿、原生 DSH 接入与动画边界。

面向自然语言投研的独立产品候选。DSH 负责 Agent、会话、模型、工具和 Skill；Python 负责权威业务状态、证据和有界研究；产品安装层管理实例和后台生命周期。

当前包版本 `1.0.0`，固定 DSH `0.2.1-rc.2`，保留 `private: true`。这是一份供同事继续开发与验收的候选源码；没有发布到 npm，也不代表真实研究、M1/M2 或跨平台验收完成。目标 GitHub 仓库为 `PABIPRG/investment-research-agent`，源码导出不携带原仓 Git 历史。

人工体验与自然语言冒烟请按[启动指引](docs/启动指引.md#首次安装到持久实例)安装、启动持久实例，在左下角「设置 → 模型」配置 API Key；不需要登录 DeepSeek 平台账号。以下命令用于开发者检查与固定场景回放，不能替代正常产品入口。

```sh
npm ci --ignore-scripts
npm run check
npm run build
npm run smoke:skills
```

上述受控回放需要可用 Python 依赖，按启动/开发指引建立自己的虚拟环境；不读取旧实例，不使用真实模型或行情。普通产品入口需用户在本机配置模型，不能把受控模型当真实研究。
