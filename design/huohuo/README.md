# 火火暖橙柔粉腮红母版

- 本机可编辑 Blender 母版包含完整动作库和放大镜动作。按用户决定，母版仅保留在本机，不纳入公开仓库和交接包；需要改动角色源文件时由持有人提供。
- `header-peek-master.png`：用户已确认的最初设计图经 imagegen 调整，透明背景，一手握镜、一手扒栏，下半身水平裁切。
- `idle-cheeks-master.png`：从新版 Blender 完整动作库的待机代表帧渲染，作为头像、favicon 和 WebGL 后备的母图。

在装有 Pillow 的 Python 环境执行 `python3 scripts/export-brand-assets.py`，从公开的透明母图导出运行时 PNG/ICO 并更新资源指纹；此工具不属于用户安装依赖。运行时所需 GLB 与图标包含在产品源码中。

运行时保留已有 GLB 的几何、12 动画及 Three.js 生命周期。柔粉腮红由同一身体材质叠加，参数对应 Blender 的左右中心 ±0.58、脸颊高度 1.56、宽 0.215、高 0.105、混合强度 0.88。Blender Z-up 对应 GLTF Y-up，朝向为 GLTF +Z。使用变形前的模型局部坐标，腮红随网格形变和整体转向，不依赖屏幕坐标；背面不绘制。

Blender 程序材质并未烘焙到 GLB；不要把该 GLB 当作可在任意播放器独立复现暖橙腮红的通用材质产物。产品视觉由模型与现有 renderer 共同构成。放大镜动作仍为设计源，顶部栏当前采用已确认静态图标。


2026-10-27 产品显示校色：顶部图标仍使用已确认母图；运行时身体显示色度倍率1.6、橙黄色区黄色偏向修正0.04，以修复相对图标偏浅偏黄。参数由renderer.js和resource-manifest.json记录，导出脚本保留该修订。Blender设计源、GLB几何与12动作没有因此改写；不要把浏览器显示校色误认为模型基础材质已经重新烘焙。
